Each session gets

Its own user (niuu-slot-n), network namespace with NAT out of the host, PID namespace, private /tmp, and a cgroup slice with the limits above. No sudo, no Docker group. LAN addresses are denied unless listed in the pool's allowed LAN ranges.

When a session stops

Its slot is archived and torn down, then checked: no process, file, namespace, rule or slice of that user may be left. Only then is the slot offered again. Anything left keeps the slot out and shows here.
