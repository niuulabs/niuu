Each session on this host gets

Its own user, network namespace (NAT out, LAN denied except allowed ranges), process namespace, private /tmp and a cgroup slice with the limits above. No sudo, no Docker group; rootless Podman for its containers.

When a session stops

Its slot is archived and torn down, then checked: no process, file, namespace, rule or slice of that user may remain. Only then is the slot used again. Anything left keeps the slot out and shows on the host's row.

Targeting

A session or workflow targeting fast-disk can now land here. With site:hnoss it also matches the other hosts at hnoss.

If Forge can no longer reach a host, removing it still cuts it off at once. To clean up the host itself, run sudo niuu-host-leave there.
