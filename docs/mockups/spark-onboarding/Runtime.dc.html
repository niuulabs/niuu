Runtime and access

Where sessions execute, where their files live, and who can reach this Niuu.

Where sessions run
Each session gets its own runtime with the GPU, your Git credentials and the workspace mounted in.
OpenShell sandboxRecommended
Isolated NVIDIA OpenShell sandbox per session with a network policy. Credentials are injected per session, never written to disk inside it.
Docker container
One container per session on the host daemon. Simpler, weaker isolation.
Host processNot isolated
Runs Claude and Codex directly on this machine. No isolation; single trusted user only.
Workspaces directory
/var/lib/niuu/workspaces
3.2 TB free · clones, build caches and session scratch live here
Keep workspaces after a session ends
Reopen later or let a resident continue the work.
Who can reach this Niuu
Sign-in is off by default. Turn it on later in Settings → Access.
Only this machine
localhost:8080
Your local network
http://spark.local:8080 · anyone on the LAN
Public, behind sign-in
Reverse proxy with HTTPS and an identity provider (OIDC). Set up later in Settings → Access.
Anyone who can open spark.local:8080 can start sessions on this Spark.
