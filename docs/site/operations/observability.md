# Observability

Use logs, telemetry, topology, and event streams to understand the platform.

## Surfaces

- Platform logs under the local dev run directory
- Session logs and telemetry in Völundr
- Topology and event context in Observatory
- Provider health and usage in Bifröst
- Workflow run state in Ting
- Knowledge health in Mímir

For production, connect logs, metrics, and traces to your infrastructure observability stack.
