# Workflows And Teams

Use workflows when work should move through multiple roles or stages.

Ting coordinates reusable workflow definitions, dispatch queues, stages, resources, gates, and run state. It is the layer for work that needs more structure than one assistant in one workspace.

## When to use a workflow

- A task needs several specialist roles.
- A human gate should approve a stage.
- Work should be retried, escalated, or reviewed consistently.
- A recurring process should be modeled once and reused.

## Relationship to sessions

Workflows can launch or coordinate sessions, but sessions remain the place where concrete workspace activity happens.
