# Agents And Personas

Understand how Niuu represents assistant behavior.

Ravn manages personas, assistant instances, triggers, sessions, budgets, and longer-lived behavior. A persona describes how an assistant should work; an assistant instance applies that behavior in a runtime context.

## Common uses

- Coding and review assistants
- Research assistants
- Security or operations specialists
- Resident assistants that watch events and ask for help when needed
- Warden assistants that curate Mímir knowledge

## Human guidance

Assistants should be able to ask for help, pause at gates, and resume with context. Operator visibility is part of the model, not an afterthought.
