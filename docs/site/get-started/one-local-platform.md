# One local platform

Use the [first-session quick start](first-local-stack.md) for the canonical local
setup. It explains the tools, login, initialization, start command, health check,
and shutdown, followed by a complete session exercise.

A release binary runs in the foreground with `niuu platform up`; stop it with
Ctrl+C. The contributor script `./start-dev` runs in the background; stop that
stack with `./stop-dev`.
