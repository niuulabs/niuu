# HTTP API

Humans and agents use the same service APIs. For local mini mode, the platform
origin is normally `http://127.0.0.1:8080`; shared deployments use their configured
authenticated gateway origin.

## Start with a read

With the local platform running:

```bash
curl --fail --silent --show-error http://127.0.0.1:8080/health
curl --fail --silent --show-error http://127.0.0.1:8080/api/v1/forge/sessions
```

The first checks the host; the second lists sessions visible to the caller.
A successful health check does not validate model access. A shared deployment
may require authentication for these reads; use its normal identity flow.

## Route ownership

| Surface | Route prefix | Responsibility |
| --- | --- | --- |
| Forge | `/api/v1/forge` | Sessions and workspace operations |
| Runtime definitions | `/api/v1/volundr/session-definitions` | Launch runtime catalog |
| Ting | `/api/v1/ting` | Workflows, sagas, runs, and review |
| Mímir | `/api/v1/mimir` | Knowledge, sources, search, and curation |
| Bifröst | `/api/v1/bifrost` | Catalog and inference gateway |
| Guild | `/api/v1/niuu/instances`, `/api/v1/niuu/targets/volundr` | Instance discovery and target selection |
| Ravn | `/api/v1/ravn` | Agent runtime services |
| Setup | `/api/v1/niuu/setup` | First-launch wizard: progress (`GET`, `PUT /steps/{step}`, `POST /complete`, `POST /reset`) and host report (`GET /system`). Writes need `volundr:admin`; `enabled` is `false` unless the host set `NIUU_SETUP_ENABLED`. |

The host mounts the domains declared by enabled plugins. A disabled service can
produce a missing route; an unreachable remote service can produce a gateway
failure. Inspect the service owner before changing a URL.

## Schemas and their scope

The [downloadable OpenAPI schema](../openapi.json) is generated by
`scripts/extract_openapi.py` from Völundr routers. It is **not an aggregate schema
for every Niuu service**. Use each service's exposed OpenAPI document for its exact
request models, authentication requirements, response schemas, and status codes.

Do not construct endpoints from UI labels. The runtime-definition catalog, for
example, still uses `/api/v1/volundr`, while session operations use `/api/v1/forge`.
[Session reference](sessions.md) lists the verified local lifecycle routes.

## Writing reliable clients

Handle non-success status codes before parsing a success model. Preserve returned
IDs and endpoints rather than reconstructing them. For live sessions, HTTP
lifecycle operations and streamed runtime messages are separate protocols;
reconnecting a stream must not create another session.

Use the [CLI](cli.md) where it already covers the operation. For automation of the
local tutorial, `scripts/check_quickstart.py` is a runnable lifecycle example.
