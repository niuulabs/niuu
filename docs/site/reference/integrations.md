# Integrations Reference

Integrations connect Niuu to external tools and providers.

## Common integration areas

- GitHub or GitLab for repositories and pull requests
- Linear, Jira, or other trackers for work intake
- OIDC providers for identity
- Vault-compatible systems for secrets
- Model providers such as OpenAI, Anthropic, or local Ollama-compatible runtimes
- Event systems such as NATS, RabbitMQ, and OpenTelemetry

Configure integrations through service configuration, settings, or deployment values depending on the target environment.
