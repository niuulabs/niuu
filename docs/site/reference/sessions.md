# Sessions Reference

Sessions are the core runtime object for live AI work.

## What a session tracks

- Name, state, owner, and runtime target
- Repo and branch context
- Launch preset and model settings
- Chat endpoint and live broker state
- Files, diffs, logs, telemetry, and chronicles

## Operator actions

Operators can create, start, stop, archive, inspect, and review sessions. Exact available actions depend on the active runtime and service configuration.
